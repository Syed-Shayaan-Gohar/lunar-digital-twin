# Lunar Digital Twin — Leo Rover / LunaLab

Digital twin of a fictionlab Leo Rover operating in a simulated lunar
environment, replicating the setup described in:

Rodríguez-Martínez et al., "SPICE-HL³: Single-Photon, Inertial, and Stereo
Camera dataset for Exploration of High-Latitude Lunar Landscapes,"
*Scientific Data*, 2026.
